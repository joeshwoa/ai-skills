# Instructional design — the studio's method

## Backward design (always in this order)
1. **Outcomes** — what learners can DO at the end (3–8 per course, 2–4 objectives per session).
2. **Evidence** — how we will know (assessments mapped to outcomes, weights = 100%).
3. **Learning experiences** — sessions, activities, content that build towards the evidence.
Alignment matrix: every outcome → ≥ 1 session that teaches it → ≥ 1 assessment that measures it.

## Bloom's verbs (EN / AR — use the learner-facing form)
| Level | English | العربية |
|---|---|---|
| Remember | define, list, name, recall, identify | يعرّف، يذكر، يسمّي، يحدد |
| Understand | explain, describe, summarise, classify, compare | يشرح، يوضح، يلخص، يصنف، يقارن |
| Apply | use, solve, write, implement, calculate, demonstrate | يستخدم، يحل، يكتب، ينفذ، يحسب، يطبق |
| Analyze | analyse, debug, trace, differentiate, organise | يحلل، يتتبع، يصلح، يميّز، يرتب |
| Evaluate | justify, critique, choose, assess, test | يبرر، ينقد، يختار، يقيّم، يختبر |
| Create | design, build, develop, plan, produce | يصمم، يبني، يطور، يخطط، ينتج |
Avoid "know", "understand", "learn about", "يعرف عن", "يفهم" as objectives — not measurable.
Progress through levels across a course: early sessions remember/apply, later analyse/create, the
final project creates.

## Session architecture (Gagné + I do/We do/You do)
| Phase | Share of time | Purpose |
|---|---|---|
| Hook / activate prior knowledge | 5–10% | a question, a problem, a story, a demo |
| Objectives | 2–3% | "by the end you can…" (slide + say it) |
| Explain (I do) | ≤ 15 min per chunk | one concept, concrete example, visual |
| Worked example / guided (We do) | 15–20% | think aloud, students predict |
| Practice (You do) | 35–50% | individual/pairs, increasing difficulty |
| Check for understanding | 5–10% | quiz, exit ticket, show-me boards |
| Recap + homework | 5% | 3 takeaways, what's next |
90-minute school lab session: 10 hook · 15 explain · 10 check · 15 explain · 25 practice · 10 quiz/
recap · 5 save/close. 3-hour workshop: two 80-minute blocks + break; build a project end to end.

## Content writing
- Concrete before abstract: example → rule → another example → non-example.
- One new idea per chunk; name it, define it, show it, use it.
- Worked examples with the reasoning written out; then faded examples (fill the missing step).
- Analogies from the learners' world (school, football, mobile games, the market, the workshop).
- Anticipate misconceptions and address them explicitly (misconceptions list per session).
- Retrieval practice: start each session with 2–3 questions from the previous one; spaced review.
- Cognitive load: short sentences, one visual per idea, no decorative clutter on teaching slides.

## Differentiation
Support: partially completed code/answers, word banks, worked example nearby, pair with a peer.
Extend: an open challenge, a constraint ("without a loop"), teach-back, real-world variant.

## Projects
A final project per course that integrates the outcomes; brief + milestones + rubric (3–4 criteria
× 4 levels) + exemplar description. Prefer authentic tasks (a tool the school uses, a local
business problem, a portfolio piece).
