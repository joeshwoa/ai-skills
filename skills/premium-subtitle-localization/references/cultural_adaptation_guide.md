# Cultural adaptation guide

Concrete patterns for Pass 3 of `translation_workflow.md`. All examples
below are invented for illustration — never lift real dialogue examples
from a copyrighted film into this file; when documenting a real project,
keep worked examples in that project's own private notes, not in this
shared skill.

## Categories of culture-bound content, and the move for each

**Idioms** — a fixed phrase whose meaning isn't literal ("it's raining
cats and dogs"). Translate the *meaning*, using the target language's
own idiom for the same meaning if one exists ("il pleut des cordes" in
French), otherwise a plain non-idiomatic phrase ("it's pouring"). Never
translate an idiom's words literally — "تمطر قططا وكلابا" means nothing
in Arabic and breaks the moment instead of describing weather.

**Wordplay/puns** — jokes that work because of how the source language's
words sound or are spelled. These essentially never survive literal
translation. Options, in order of preference:
1. Find a *different* pun in the target language that fits the same
   scene/moment (a different word pair, same comedic mechanism).
2. If no pun is possible, replace it with a different kind of joke that
   fits the character and moment (irony, exaggeration, a callback to
   something established earlier) — losing the pun-ness is fine, losing
   the laugh is not.
3. Only as a last resort, drop the joke and translate the line straight
   — better than a confusing non-joke, but log it as a note so a human
   reviewer knows a joke was sacrificed.

**Local references** (celebrities, brands, foods, places, politicians)
— ask whether the reference itself matters or is just flavor:
- *Flavor only* (a throwaway name-drop): substitute a neutral
  equivalent, or a generic descriptor, in the target culture.
- *Matters to the joke*: substitute a target-culture reference that
  plays the same *role* (a "everyone knows this is cheesy" singer, a
  "everyone's uncle has one" car) rather than trying to explain the
  source reference.

**Religious/social register** — some source-language politeness markers,
honorifics, or religious expressions (e.g. Arabic "إن شاء الله") carry
social meaning with no single equivalent. Translate the *social function*
(hedging a promise, expressing hope) rather than the literal words —
"God willing" reads as much more overtly religious in many target
languages than the source expression felt to its own audience; a
target-language hedge like "hopefully" is often the more faithful
choice, not a mistranslation.

**Swearing/register intensity** — profanity strength doesn't map 1:1
across languages or cultures; match the *social force* of the word (how
shocking/casual it is to that audience) rather than a dictionary
equivalent. A mild source-language curse translated to a target
language's much stronger equivalent (or vice versa) changes the
character.

## When to add an in-line hint vs. when to just substitute

Add a brief woven-in hint only when **both** are true: the reference
matters to understanding the scene, AND no clean target-culture
equivalent exists. Otherwise substitute cleanly (most cases) — subtitles
have no room for "translator's notes," and a viewer stopping to parse an
explanation breaks immersion worse than a slightly-adapted reference
would. When a hint is genuinely warranted, keep it to a couple of words
folded naturally into the line, never a parenthetical aside or a
sentence-length explanation — it has to survive `subtitle_standards.md`'s
reading-speed limits like any other line.

## Arabic comedy specifically (Joshua's stated use case)

Egyptian/Arabic comedy leans heavily on: fast wordplay, proverb
mangling (twisting a well-known proverb for a laugh — the joke depends
on the audience knowing the *real* proverb), and register-switching
(a character suddenly speaking very formally, or very crudely, for
comic effect). For all three:
- Proverb-mangling almost never survives literal translation (the target
  audience doesn't know the original proverb, so the twist is invisible)
  — find a target-language saying/cliché the audience *does* know, and
  mangle that one instead, preserving the "twisted-cliché" mechanism
  rather than the specific proverb.
- Register-switching *does* usually translate directly — most languages
  have an equivalent formal/informal or crude/polite axis a translator
  can shift along; keep the switch, even if the specific words change.
