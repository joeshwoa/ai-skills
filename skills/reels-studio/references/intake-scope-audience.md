# Intake — scope & audience first

Never assume a detail that changes the output. Ask as numbered multiple choice, one
**RECOMMENDED** option each, a final "you decide", max 6 questions per message, answerable in one
line ("1b 2a 3c"). Pre-fill everything already known (brand file, earlier scripts, the user's
examples, memory) and don't re-ask it. Ask in the user's language (Arabic for Arabic speakers,
short). Escape hatch: "just go" / "كمّل" / "all recommended" → take every recommended option and
print one compact line of assumptions.

## Round 1 — the job (always)
1. **Platform(s)** — a) Instagram Reels b) TikTok c) YouTube Shorts d) Facebook Reels
   e) LinkedIn f) Snapchat Spotlight g) all vertical (RECOMMENDED: write once, adapt the posting
   pack per platform)
2. **Goal (one)** — a) awareness/reach b) engagement/community c) followers d) consideration
   (understand the offer) e) leads/sign-ups f) sales g) retention/loyalty
3. **Who exactly is it for?** — offer 3–4 concrete personas derived from the brief + "other"
4. **Language & dialect** — a) Egyptian Arabic with English terms (RECOMMENDED for Egypt-based
   audiences) b) Gulf/Saudi c) Levantine d) MSA e) English f) bilingual g) other
5. **Length** — a) 7–15 s b) 20–35 s (RECOMMENDED for reach) c) 45–60 s (RECOMMENDED for
   explaining an offer) d) 60–90 s e) longer (YouTube Shorts / TikTok allow it — retention must earn it)
6. **Format & who's on camera** — a) talent to camera b) founder/executive statement
   c) voice-over + B-roll/screens d) skit e) text-only f) UGC/testimonial (real person, consent)
   g) tutorial/listicle h) AI-generated video

## Round 2 — only what's still unknown
- **Scope**: one reel / series of N (recurring opening, same format) / campaign phases.
- **CTA**: follow, comment (a real question), save, share/send, DM keyword, link in bio, register, buy, none.
- **Offer facts**: name, price, dates, deadlines, guarantees — from the user only; never invent.
- **Talent**: who, their on-camera comfort, will they memorise or read a teleprompter.
- **Production level**: phone, studio, location shoot, AI-generated, screen recordings.
- **Brand rules**: tone words, banned words/visuals, logo/end-frame rules, reference creators.
- **Account type**: creator or business (affects trending-audio rights).
- **Deadline & posting date** (to match occasions and trend timing).

## Persona card (write into brief.md and spec.brief.audience)
```
Who:            role, age band, city/country, income/education band if relevant
Knows already:  what they've tried, tools they use, words they use for the problem
Stage:          unaware | problem_aware | solution_aware | product_aware | most_aware
Pain (their words):   "…"
Desire (their words): "…"
Objections:     price, time, "AI will replace me", trust, …
Scroll context: where, when, sound on/off, which creators they follow
Language:       dialect, English mixing level, formality, spelling habits (Arabizi in comments?)
```

## Awareness stage → what the reel must do
| Stage | Viewer thinks | Reel job | Good formats |
|---|---|---|---|
| Unaware | nothing about this | entertain / name a hidden problem | skit, POV, relatable pain, trend |
| Problem-aware | "this is annoying" | agitate + hint there's a better way | myth vs fact, mistakes, story |
| Solution-aware | "there must be a way" | show *the way* and why it works | tutorial, before/after, demo |
| Product-aware | "is yours good?" | proof, differentiation | testimonial (real), comparison, behind the scenes |
| Most-aware | "when / how much?" | offer + urgency + one clear step | direct CTA, event/date, FAQ answer |

## Goal → metric → CTA
| Goal | Primary metric | CTA that fits |
|---|---|---|
| Awareness | reach, 3-s hold, average watch % | none or follow |
| Engagement | comments, shares/sends | a real question; "send this to …" |
| Followers | follows per reach | "follow for part 2" (only if part 2 exists) |
| Consideration | saves, profile visits, watch-through | save; "details in bio" |
| Leads | DMs/keyword replies, link clicks, sign-ups | DM keyword / register |
| Sales | clicks, conversions | link + offer + deadline |

## Scope sizes
- **One reel**: 1 idea, 1 hook + 2 alternates, 1 script.
- **Series**: a named format with a fixed opening line/visual, numbered episodes, each standalone
  but pointing to the next; plan all titles before writing episode 1.
- **Campaign**: phases with dates (tease → reveal → explain → proof → urgency → last call),
  2–4 reels per phase, mixed talents/formats (e.g. founder statement + COO + host + instructor),
  one shared end frame and CTA language.
