# Languages & dialects — write how people talk

A reel script is spoken, so it's written in the **spoken variety of the audience**, not the
standard written form. Set `spec.language` to a precise tag: `ar-EG` (Egyptian), `ar-SA` (Saudi),
`ar-AE` (Emirati), `ar-KW`, `ar-LB`/`ar-SY`/`ar-JO`/`ar-PS` (Levantine), `ar-IQ`, `ar-MA` (Moroccan
Darija), `ar-TN`, `ar-DZ`, `ar` (MSA — only when the brief asks for formal Arabic), `en-US`,
`en-GB`, `en` (global), `fr-FR`, `es-ES`/`es-MX`, `de-DE`, `tr-TR`, `ru-RU`, …

## Process for any language
1. Write the idea and beats in the language you think best in.
2. **Transcreate** (don't translate) into the target variety: same intent and punch, local
   idiom, local examples, local units/currency, local references.
3. Read it aloud in that accent (in your head): every line must sound like a person from that
   audience talking to a friend at the register the brief chose.
4. Keep brand and product names, programme names and technical terms the way that audience
   actually says them (often English).
5. Check numbers, dates, currency and plurals in the target language.
6. If you aren't confident in a variety, say so and recommend a native read-through before the shoot.

## Egyptian Arabic (ar-EG) — the default for Egypt-based audiences
**Core grammar & words**
| MSA (avoid in speech) | Egyptian |
|---|---|
| هذا / هذه / هؤلاء | ده / دي / دول |
| ماذا / لماذا / كيف / متى / أين | إيه / ليه / إزاي / إمتى / فين |
| ليس / لا (with verbs) | مش / ما…ش (ماعرفش، مابقاش) |
| سوف / سـ | هـ (هتتعلم، هنشوف) |
| present continuous | بـ (بتستخدم، بنقدم) |
| الذي / التي / الذين | اللي |
| يجب / ينبغي | لازم / المفروض |
| الآن | دلوقتي |
| جداً | أوي / جدًا / خالص |
| أيضاً | كمان / برضه |
| لكي / من أجل | عشان |
| نحن / أنتم / هم | إحنا / إنتو / هما |
| يريد | عايز / عاوز |
| يستطيع | يقدر |
| هناك (exists) | فيه |
| فقط | بس |
| كثير | كتير |
| حسناً | تمام / ماشي |
| ما زال | لسه |
| أريد أن أقول | عايز أقولك |

**Rhythm devices:** "خليني أسألك…", "ببساطة…", "يعني مش بس…", "وده بالظبط اللي…", "الفكرة إن…",
"بص…", "تخيل…", "خد بالك…", "والأهم بقى…", "مستنيينك".

**Code-switching (the Neo AI register):** professionals in Cairo say industry terms in English:
`الـAI`, `الـbusiness`, `الـcareer`, `الـtools`, `الـModel`, `الـOutput`, `Up to Date`, `next step`.
Write the English word in Latin letters, attach `الـ` directly for "the" (الـAI), keep Arabic
conjunctions attached (والـTools، للـBusiness Owner). Don't over-mix: one or two English terms per
sentence; the sentence skeleton stays Egyptian. Keep it consistent with how the brand's earlier
scripts did it.

**Spelling conventions (be consistent):** ده/دي not دا/دى; إزاي not ازاى; عشان; دلوقتي;
مش; هـ attached (هيتغير); hamza on إ/أ where standard; final ي dotted. Numbers: Western digits
(12, 2026) when mixing with English; Arabic-Indic (١٢) for fully Arabic on-screen text if the brand
prefers — pick one per piece.

**Register options:** casual-street (youth, comedy) → friendly-professional (most brand content,
the Neo AI default) → formal-Egyptian (executives; fewer slang words, still ده/مش/هـ).

**Validator:** for `ar-EG` it flags common MSA words (سوف، لماذا، هذا، الذي، يجب، الآن…). It can't
judge naturalness — read it aloud.

## Gulf (ar-SA / ar-AE / ar-KW / ar-QA)
وش/ايش (what), ليش (why), كيف (how), وين (where), متى; هذا/هذي (Saudi), ذا; أبي/أبغى (I want),
بـ / راح (future), ما/مو (negation), زين (good), مرة (very — Saudi), واجد (much — Kuwait/UAE),
الحين (now), يالله. Saudi youth content mixes Najdi/Hijazi; ask which. Keep respectful register;
avoid Egyptian-only words (ده، إزاي، عايز).

## Levantine (ar-LB / ar-SY / ar-JO / ar-PS)
هيدا/هيدي (LB), هاد/هاي (SY/JO/PS); شو (what), ليش (why), كيف (how), وين (where); بدّي (I want),
رح (future), عم (progressive: عم بشتغل), ما/مش (negation), كتير (very), هلّق/هلأ (now), منيح (good).
Lebanese content mixes French ("merci", "bonjour", "ça va") and English.

## Maghrebi (ar-MA / ar-DZ / ar-TN)
Moroccan Darija: شنو/آش (what), علاش (why), كيفاش (how), فين (where), بغيت (I want), غادي (future),
ما…ش (negation), بزاف (a lot), دابا (now), واخا (ok); heavy French mixing. Tunisian: شنوّة، علاش،
كيفاش، توّا (now), برشا (a lot). Ask for a native check — these differ strongly from Mashreqi Arabic.

## Iraqi (ar-IQ)
شنو/شكو (what/what's up), ليش, شلون (how), وين, أريد (I want), راح (future), هسّة (now), كلش (very).

## MSA (ar)
Use only when the brief wants formal (government, some institutions, pan-Arab corporate). Even then:
short sentences, active verbs, no ornate classical phrasing.

## Arabizi / Franco (comments, captions for youth)
"ezayak", "3ashan", "7elw" — only in captions/on-screen for audiences who type that way; never for
the spoken script field (talent reads Arabic script).

## English
- **en-US / en-GB / global**: spelling and words (color/colour, apartment/flat), date formats,
  currency. Global English for MENA audiences: simple words, no idioms that need US context.
- Spoken style: contractions (you're, don't), fragments are fine ("Not the model. The thinking.").

## Other languages (French, Spanish, German, Turkish, Russian, Hindi, Urdu, Persian, Chinese…)
Same process: transcreate, match formality to culture (tu/vous, tú/usted, du/Sie, ты/вы), local
examples and currency, local platform habits (e.g. different platforms dominate in some markets).
Speaking rates in `scripts/reelspec.py` (chars/s for Chinese/Japanese/Korean/Thai). Recommend a
native reviewer for any language you aren't strong in.

## Right-to-left documents
The renderer aligns RTL scripts right and keeps Latin-only lines readable; mixed lines are laid out
RTL. Write naturally — don't insert manual direction marks. Put English terms inside Arabic
sentences as they're spoken.
