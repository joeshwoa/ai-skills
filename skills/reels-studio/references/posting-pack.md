# Posting pack, testing and learning

Every script ships with a `posting` block (rendered as the last page, POSTING PACK):

| Field | What good looks like |
|---|---|
| `cover_text` | 3–5 words, the promise or the tension ("مش محتاج أغلى Model"); readable on a phone grid |
| `caption` | line 1 = a second hook (it shows before "more"); 1–3 short lines of value; the CTA; searchable keywords in plain words |
| `hashtags` | 3–5 specific ones (brand, topic, niche, local language) — no generic #viral #explore |
| `first_comment` | optional: a question to start discussion, or the link/keyword for the CTA |
| `title` | YouTube Shorts title ≤ 100 chars, keyword first |
| `alt_hooks` | 2–3 alternate opening lines for A/B or re-cuts |
| `best_time` | from the account's Insights; otherwise a general guess labelled as such |

## Caption formulas
- **Hook → value → CTA**: "كل أسبوع Model جديد… بس النتيجة مش بتيجي من السعر. [value]. [CTA]"
- **Question → answer teaser → CTA to watch/save**.
- **Story line → lesson → CTA**.
Arabic captions: same dialect as the video; English terms as in the script; emoji only if the brand uses them.

## CTA menu (one per reel)
Follow for part 2 (only if it exists) · save this for later · send this to a friend who… ·
comment with your answer to <real question> · DM us "<keyword>" · link in bio · register /
book / buy before <date> · nothing (pure entertainment). Avoid engagement bait ("comment YES",
"tag 5 friends") — Meta and TikTok demote it.

## A/B testing hooks
- Instagram **Trial Reels** (non-followers first) or post the same body with a different hook a week
  apart; TikTok: different hooks on different days. Change one thing at a time (the hook), keep the body.
- Read **3-second hold / views vs swipe-away** for the hook, **average watch %** for the body,
  **shares/sends and saves** for value, **follows/profile visits/link clicks** for the CTA.

## After posting — the learning loop
At 24 h and 7 days ask the user for: views, reach (followers vs non-followers), 3-s hold or
"viewed vs swiped", average watch time and %, completion, shares/sends, saves, comments,
follows, link clicks/DMs.
Decision rules:
- low hold (people swipe in 1–3 s) → the hook failed: new hook, same body;
- good hold, early drop → the setup is slow: cut the first beat after the hook;
- good watch, few shares/saves → the payoff isn't useful/emotional enough;
- good everything, no action → the CTA is weak or mismatched to the stage.
Write the lesson into the brand file (`notes` list) so the next script starts smarter, and log a
skill usage report.
