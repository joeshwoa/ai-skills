# Post pack template
Last updated: 2026-10-19

One pack per post and platform. Fill every field or write `n/a`. Check text with `python3 scripts/limits_check.py <platform> --field caption --file draft.txt`, then run the platform file's pre-publish checklist (section 12) and the release gate (`references/compliance-and-ethics.md` section 11).
